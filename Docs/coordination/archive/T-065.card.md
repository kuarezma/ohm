# T-065 — İmzasız önizleme sürümü (Developer ID yok) — Gemini 3.8 Flash high

Kullanıcının Apple hesabı ücretsiz "Personal Team"; Developer ID ve notarization yok (HANDOFF 2026-09-30). Bugün `scripts/ci/release.sh` canlı modda secret yoksa **paket üretmeden** `exit 0` yapıyor; tag'le sürüm çıkarsa hiçbir şey yayınlanmıyor.

## Kapsam
`scripts/ci/release.sh`, `.github/workflows/release.yml`, yeni `packaging/preview/FIRST-RUN.md` (EN) + `FIRST-RUN.tr.md` (TR), `README.md`/`README.tr.md` yalnız "Kurulum" bölümünde önizleme sürümü paragrafı. Dokunma: `app/**`.

## Davranış
1. `release.sh` modları: **signed** (5 secret var → bugünkü Developer ID + notarize yolu, değişmez), **preview** (secret yok → yeni yol), `--dry-run` (bugünkü, değişmez).
2. **preview:** Release derlemesi `CODE_SIGNING_ALLOWED=NO`, sonra içten dışa **ad-hoc** imza (`codesign --force --sign - --options runtime`, entitlement'lar T-060'daki gibi açılmış). Not: ad-hoc imzada takım öneki yok — App Group entitlement'ı ad-hoc imzada geçerli olmaz; bunu **kanıtla test et** (ad-hoc imzalı app'i `open -n` ile aç, `/usr/bin/log show --predicate 'subsystem == "dev.ohm"'` içinde `runtime started` mı `runtime start failed` mı çıkıyor). Başarısızsa: önizleme için yerel imzalı derlemeyi (geliştiricinin `Local.xcconfig`'i ile, Personal Team) kullanan yolu uygula ve CI'da preview'ın yalnız "kaynaktan derleme" talimatı üreteceğini açıkça yaz — hangisinin çalıştığını ölçümle raporla, tahmin etme.
3. Zip adı `Ohm-<sürüm>-preview.zip` + `.sha256`; zip içine `FIRST-RUN.md`. İlk açılış notu: Sistem Ayarları › Gizlilik ve Güvenlik › "Yine de Aç" adımı ve alternatif `xattr -dr com.apple.quarantine /Applications/Ohm.app` — sade dil, neden imzasız olduğu tek cümle.
4. `release.yml`: tag'de preview modunda zip'i GitHub Release'e **pre-release** olarak ekle (`softprops/action-gh-release@v2` veya `gh release create --prerelease`), secret'lar varsa normal sürüm.
## Kabul (kendin koş)
`scripts/ci/release.sh` (secret'sız, canlı mod) → exit 0, `build/ci/Ohm-<v>-preview.zip` + sha256; zip içeriğinde `Ohm.app`, `FIRST-RUN.md`, widget ve `Contents/Helpers/ohm`. 2. maddedeki ölçüm kanıtı. `scripts/ci/release.sh --dry-run` ve `scripts/ci/build-test.sh` hâlâ exit 0. YAML `ruby -ryaml` ile geçerli.
Açtığın Ohm süreçlerini kapat, geride süreç bırakma. Commit/push etme. Rapor `.result.md`.
