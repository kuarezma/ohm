# T-035 — Kural motoru ve doğal dil kuralını uygulamaya bağla — GPT-6.1 Sol medium

T-034 ile `OhmRuntime` (app/OhmApp/Runtime/) örnekleme, ledger, tahmin, kaçak dedektörü ve Governor'ı bağladı. Kurallar hâlâ bağlı değil: `LiveDataSource` içindeki `addRule`/`toggleRule`/`deleteRule` ve asla-dondurma listesi şu an yalnız oturum içi/"kullanıma açık değil" davranışında. Bu görev ADR 0003'ü (kural DSL'i, bağlam olayları, `DesiredState`) uygulamaya bağlar.

## Kapsam
- `app/OhmApp/Runtime/*` (yeni dosya serbest, ör. `RuleStore.swift`, `ContextBridge.swift`), `app/OhmApp/Model/OhmStore.swift` yalnız gerekiyorsa, `Docs/adr/0001-modules-and-concurrency.md` / `0003-rule-dsl.md` yalnız gerçekleşen bağlantıyı yazmak için.
- Dokunma: `app/OhmCore/**` (eksik public API gerekirse DUR ve raporla), Views (yalnız veri kaynağı davranışı değişir), entitlements.

## Davranış
1. **Kalıcılık:** kurallar ve asla-dondurma listesi App Group kapsayıcısında (T-034'ün `appGroupIdentifier()` ile çözdüğü `<TEAM>.dev.ohm`) tek JSON dosyasında, atomik yazım (geçici dosya + rename), sürüm alanı. Bozuk dosya: yedeğe al, boş listeyle aç, kullanıcıya bir kez bildir; asla sessizce silme.
2. **Değerlendirme:** kural değerlendirmesi tick'e değil **bağlam olaylarına** bağlı (ADR 0001 §2, ADR 0003): güç kaynağı/pil yüzdesi eşik geçişi, termal seviye, ön plan uygulaması (T-034 `WorkspaceBridge`), saat penceresi sınırları, Focus (varsa; yoksa ADR'de belirtildiği gibi). RuleEngine çıktısı `DesiredState` → `governor.reconcile`. Elle eylemler (`ManualContribution`) kurallarla birleşir; T-026b kararları korunur (`.rule` otomatik, topoloji vetosu veto nedeni olarak UI'a).
3. **Doğal dil:** `addRule(description:)` → `NLRuleParser`. `.ready` → kaydet, `enabled = false` (ADR 0003: kullanıcı açar). `.needsClarification` / `.unsupported` → kullanıcıya soruyu/nedeni göster (mevcut uyarı mekanizması; yeni UI yok), kaydetme. FoundationModels yoksa (`isNLAvailable == false`) mevcut davranış.
4. **Veto görünürlüğü:** kural etkisi Governor tarafından vetolanırsa (ör. `.unverifiedTopology`, `.appleBundle`) nedeni kuralın yanında gösterilebilecek şekilde modelde tut (Türkçe metin T-034'teki `showVetoes` eşlemesiyle).
5. **Kaçak hedefi:** `.runaway` hedefli kurallar T-032 `currentRunaways` ile çözülür; `freeze` + `runaway` zaten RuleValidator'da reddediliyor.

## Kabul
- Deterministik: mevcut `--runtime-self-check`'e kural akışı ekle (sahte bağlam olayları → beklenen `DesiredState`; kalıcılık yaz/oku/bozuk dosya; NL `.ready` → disabled kayıt). Yeni test hedefi ekleme.
- `--runtime-smoke <sn> --rules-file <yol>`: verilen JSON'daki kuralları yükler, JSON çıktısına `"rules":N,"rulesActive":N,"lastDesired":"..."` ekler. Şef şu kuralla koşacak: "pil %99'un altında VEYA adaptörde → TextEdit E-core" (TextEdit açıkken), beklenen: kural aktif, E-core etkisi uygulanır ya da veto nedeni raporlanır.
- `cd app/OhmCore && swift test` yeşil kalır. Xcode derlemesini sandbox'ta koşamazsan T-034'teki gibi kaynak derleme kanıtı ver; imzalı kapıyı şef koşar.
