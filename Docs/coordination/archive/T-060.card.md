# T-060 — CI: build, test, paketleme ve notarization hattı (dry-run) — Gemini 3.8 Flash high

Repo'nun henüz uzak deposu yok; GitHub Actions gerçekten koşamaz. Bu yüzden iş akışları, **yerelde birebir koşulabilen betikleri** çağırır; kabul, betiklerin yerel koşusudur.

## Kapsam
- Yeni: `.github/workflows/ci.yml` (push/PR: macOS runner, xcodegen, `swift test`, Xcode Debug build), `.github/workflows/release.yml` (tag `v*`: Release build, Developer ID imza, notarize, staple, zip; secrets yoksa açık mesajla atla).
- Yeni: `scripts/ci/build-test.sh`, `scripts/ci/release.sh` (`--dry-run` bayrağı: imzasız/ad-hoc Release, zip, SHA-256, sürüm bilgisi; notarytool/imza adımlarını yalnız yazdırır). Betikler `set -euo pipefail`, yol bağımsız (repo kökünü kendisi bulur), çıktıyı `build/ci/` altına yazar (gitignored olduğunu doğrula; değilse `.gitignore`'a yalnız bu satırı ekle).
- Secrets (ADR/PLAN: kullanıcı girer, şef görmez): `DEVELOPER_ID_CERT_P12_BASE64`, `DEVELOPER_ID_CERT_PASSWORD`, `NOTARY_APPLE_ID`, `NOTARY_TEAM_ID`, `NOTARY_APP_PASSWORD`. İş akışında asla `echo` edilmez; geçici anahtarlık iş sonunda silinir.
- **Kapsam dışı (kullanıcı kararı bekliyor):** Sparkle bağımlılığı ve appcast. İş akışında yalnız `# TODO(Sparkle): kullanıcı onayı bekleniyor` yorumu ve devre dışı bir adım iskeleti olabilir; uygulamaya/project.yml'a Sparkle ekleme.
- Dokunma: `app/**` kaynakları, `Docs/adr/**`.

## Rev 1 — şef review (2026-09-30)
Yerel kabul yeşil (build-test exit 0; release --dry-run zip + widget + Helpers/ohm). Ancak **canlı** (secret'lı) yol şu haliyle yanlış imza üretir. Düzelt:
1. **Entitlement açılımı:** `codesign --entitlements app/OhmApp/Ohm.entitlements` ham dosyayı veriyor; içindeki `$(TeamIdentifierPrefix)dev.ohm` açılmadan imzaya girer (App Group bozulur — T-034 kök nedeni). Açılmış entitlement kullan: `NOTARY_TEAM_ID` ile `$(TeamIdentifierPrefix)` → `<TEAM>.` yerine koyarak geçici plist üret (app ve widget için ayrı), imzadan sonra `codesign -d --entitlements - --xml` ile `<TEAM>.dev.ohm` olduğunu doğrula; değilse exit 1.
2. **Derleme imzası:** canlı modda Release derlemesini `CODE_SIGNING_ALLOWED=NO` ile yap (runner'da Apple Development sertifikası yok), sonra içten dışa Developer ID ile imzala (widget, Helpers/ohm, MacOS/ohm-thawd, app). `--deep` ile imzalama.
3. **Anahtarlık:** `security list-keychains -s` ile değiştirilen arama listesini başta kaydet, `cleanup`'ta geri yükle. notarytool parolasını argv'de geçirme: `xcrun notarytool store-credentials ohm-ci --apple-id … --team-id … --password … --keychain "$KEYCHAIN_PATH"` ile geçici anahtarlığa yaz, `submit --keychain-profile ohm-ci --keychain "$KEYCHAIN_PATH"` kullan (store-credentials argv'si kısa ömürlü; bu kabul edilebilir en iyi seçenek — notunu düş).
4. **Runner:** `runs-on: macos-15` projeyi derleyemeyebilir (deploymentTarget 26, Xcode 27). GitHub'ın Xcode 27 içeren macOS runner etiketini bul (belgeden, kanıtla) ve iki iş akışında kullan; bulamazsan `macos-latest` + `sudo xcode-select -s /Applications/Xcode_27*.app` adımı ve raporda belirsizlik notu.
5. Kanıt: dry-run'ı genişlet — dry-run'da da açılmış entitlement plist'ini üretip içeriğini (`<TEAM>.dev.ohm`, ad-hoc imzalı app üzerinde `codesign -d --entitlements`) doğrula. `build-test.sh` ve `release.sh --dry-run` yine exit 0.
