## 1. Yapılan Değişiklikler

1. **`scripts/ci/release.sh`**:
   - Developer ID ve notarization secret'ları bulunmadığında canlı modda paket üretmeden çıkmak (`exit 0`) yerine otomatik olarak **preview** moduna geçiş eklendi.
   - Sürüm paket adı `Ohm-<sürüm>-preview.zip` ve `.sha256` olarak ayarlandı.
   - Preview modunda içten dışa imzalama (`--options runtime`, `EXPANDED_WIDGET_ENTITLEMENTS` ve `EXPANDED_APP_ENTITLEMENTS` ile): yerel anahtarlıkta geçerli bir `Apple Development` (Personal Team) kimliği varsa onunla, yoksa (ör. GitHub CI ortamında) ad-hoc (`--sign -`) olarak imzalama sağlandı (`PREVIEW_SIGN_IDENTITY` ile özelleştirilebilir).
   - Önizleme zip arşivine `Ohm.app` ile birlikte `FIRST-RUN.md` (ve `FIRST-RUN.tr.md`) eklendi.
   - `unzip -l` doğrulamasında `pipefail` kaynaklı erken boru kapanması (SIGPIPE / 141) çıktının önbelleğe alınmasıyla giderildi.
   - `--dry-run` ve `signed` modları korundu.

2. **`.github/workflows/release.yml`**:
   - `permissions: contents: write` yetkisi eklendi.
   - `softprops/action-gh-release@v2` adımı eklendi: tag push tetiklendiğinde ve dry-run değilken `build/ci/Ohm-*-preview.zip` varlığı kontrol edilerek önizleme paketleri **pre-release** (`prerelease: true`, başlık: `Ohm v* (Preview)`) olarak; secret'lar mevcut olduğunda normal sürüm (`prerelease: false`) olarak yayınlanacak şekilde yapılandırıldı.
   - YAML dosyasında `'on':` anahtarı tırnak içine alınarak standart parser uyumluluğu sağlandı.

3. **`packaging/preview/FIRST-RUN.md` & `FIRST-RUN.tr.md`**:
   - Tek cümle ile neden imzasız olduğu (ücretsiz Personal Team hesabı, Developer ID bulunmaması).
   - Gatekeeper aşma adımları: Sistem Ayarları › Gizlilik ve Güvenlik › "Yine de Aç" adımı ve alternatif Terminal komutu (`xattr -dr com.apple.quarantine /Applications/Ohm.app`).
   - App Group ve kaynaktan derleme notu: macOS'un takım önekli App Group kapsayıcı erişimi kısıtı ve önceden derlenmiş ikili yerine ücretsiz Personal Team ile kaynaktan derleme talimatları.

4. **`README.md` & `README.tr.md`**:
   - Yalnızca "Kurulum / Installation" bölümü altına "Preview Releases (Unsigned) / Önizleme Sürümleri (İmzasız)" paragrafı eklendi; GitHub Releases pre-release ve `FIRST-RUN` belgelerine bağlantı verildi.
   - `app/**` dosyalarına kesinlikle dokunulmadı.

## 2. Madde 2: Ölçüm ve Kanıt Raporu (Ad-hoc vs Personal Team)

Kayıtlı sistem logları (`/usr/bin/log show --predicate 'subsystem == "dev.ohm"'`) ile test edilmiş ve ölçülmüştür:

1. **Ad-hoc İmza (`codesign --force --sign - --options runtime`):**
   - Uygulama `open -n` ile açıldığında log çıktısı:
     ```text
     2026-09-30 08:47:29.000283+0300 0x18c1f4 Error 0x0 47690 0 Ohm: [dev.ohm:runtime] runtime start failed: Error Domain=NSCocoaErrorDomain Code=513 "“ohm-probe-972BB841-A302-4889-83E7-29B6F375E848” hedefine erişim izniniz olmadığı için “ledger.sqlite” kopyalanamadı." UserInfo={NSSourceFilePathErrorKey=/Users/ugurmac/Library/Group Containers/3J22LGMHJ9.dev.ohm/ledger.sqlite, ... NSUnderlyingError=0x7bb3883c60 {Error Domain=NSPOSIXErrorDomain Code=1 "Operation not permitted"}}
     ```
   - **Sonuç:** `runtime start failed` (Hata 513 / EPERM).
   - **Kök Neden:** Ad-hoc imzada takım kimliği bulunmaz (`TeamIdentifier=not set`). macOS TCC ve `containermanagerd`, takım önekli `3J22LGMHJ9.dev.ohm` App Group kapsayıcısına erişimi engellemektedir.

2. **Personal Team İmza (`Apple Development`, Team ID: `3J22LGMHJ9`):**
   - Uygulama `open -n` ile açıldığında log çıktısı:
     ```text
     2026-09-30 09:53:05.931892+0300 0x1cff59 Default 0x0 51095 0 Ohm: [dev.ohm:runtime] runtime started protection=spawnedWatcher
     ```
   - **Sonuç:** `runtime started` (PASS).
   - **Kök Neden:** Sertifikada `TeamIdentifier=3J22LGMHJ9` bulunduğu için macOS kapsayıcı erişimine izin verir; runtime ve bağımsız izleyici daemon (`spawnedWatcher`) başarıyla başlar.

Bu nedenle:
- Yerel makinede önizleme derlemesi çalıştırıldığında anahtarlıktaki yerel `Apple Development` kimliği otomatik kullanılır.
- CI ortamında ise ad-hoc paket üretilir ve kullanıcılara App Group gereksinimi nedeniyle tam işlevsellik için kaynaktan derleme yapmaları `FIRST-RUN.md` belgelerinde açıkça bildirilir.
