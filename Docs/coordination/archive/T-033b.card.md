# T-033b — Widget: günlük pil fişi — Gemini 3.8 Flash high

`app/OhmWidget/OhmWidget.swift` bugün yalnız "Today's receipt" yazan bir iskelet. Bu görev ADR 0001 §5'teki widget'ı gerçek veriyle yapar.

## Kapsam (yalnız bunlar)
- `app/OhmWidget/**` (yeni dosya serbest), `app/OhmApp/Localizable.xcstrings` yalnız widget metni gerekiyorsa değil — widget'ın kendi `Localizable.xcstrings`'ini `app/OhmWidget/` altında oluştur (TR + EN).
- `app/project.yml` yalnız widget hedefinin kaynak/kaynak dosyası ayarı gerekiyorsa.
- Dokunma: `app/OhmApp/**` (T-035 paralelde çalışıyor), `app/OhmCore/**`, entitlements (widget'ınki zaten `$(TeamIdentifierPrefix)dev.ohm`, imzada `3J22LGMHJ9.dev.ohm`).

## Davranış (ADR 0001 §5, ADR 0002)
1. Veri: `LedgerReader` (OhmLedger) ile **salt okunur** (`SQLITE_OPEN_READONLY`, `query_only`, `busy_timeout` — LedgerReader bunu zaten yapıyorsa aynen kullan). Yol: `EnergyLedger.defaultDatabasePath(appGroupIdentifier:)`; grup kimliğini widget kendi imzalı entitlement'ından okur (`SecTaskCreateFromSelf` + `SecTaskCopyValueForEntitlement("com.apple.security.application-groups")`; takım kimliğini koda gömme — `app/OhmApp/Runtime/OhmRuntime.swift` içindeki `appGroupIdentifier()` örnek, kopyala, import etme).
2. İçerik: bugünün fişi — en çok enerji harcayan ilk 3 uygulama (ad + pil dakikası veya Wh, ADR 0002 karma fiş kuralı: yalnız pil enerjisi dakikaya çevrilir), toplam; ledger yoksa/boşsa açık bir boş durum ("Henüz veri yok — Ohm'u açın"). Tahmin/sahte veri gösterme.
3. Boyutlar: `.systemSmall` ve `.systemMedium`. SF Symbols, sistem fontu, açık/koyu, VoiceOver etiketleri, TR/EN.
4. Timeline: `.after(15 dk)` (ADR). Private API veya sinyal kodu widget'a girmez (ADR 0001 §2): OhmSampling/OhmGovernor/COhmSys import etme.
5. Widget'ın `#Preview`'ları için örnek veri yalnız preview'da.
