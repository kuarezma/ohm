# T-034 — `OhmRuntime` kompozisyon kökü — GPT-6.1 Sol high

Bugün uygulama yalnız `PreviewDataSource` ile çalışıyor; `SamplingEngine`, `EnergyLedger`, `BatteryForecaster`, `RunawayDetector`, `Governor` hiç başlatılmıyor (T-061 ölçümünde bulundu). Bu görev ADR 0001 §2 "Kompozisyon kökü"nü uygular.

## Kapsam
- Yeni: `app/OhmApp/Runtime/OhmRuntime.swift` (actor), `app/OhmApp/Runtime/LiveDataSource.swift` (`OhmDataSource` uygulaması, `@MainActor`/`@Observable`, mevcut protokolü değiştirmeden), `app/OhmApp/Runtime/WorkspaceBridge.swift` (NSWorkspace → `VisibilitySnapshot` (T-032, `OhmModel/RunawayTypes.swift`) ve Governor `WorkspaceEvent`).
- Değişebilir: `app/OhmApp/OhmApp.swift`, `app/OhmApp/Model/OhmStore.swift` (canlı kaynağı varsayılan yap; `--render-previews` ve SwiftUI Preview'lar `PreviewDataSource` ile kalır), `app/project.yml` yalnız gerekiyorsa, `Docs/adr/0001-modules-and-concurrency.md` (§2'yi gerçekleşen yapıyla güncelle).
- Dokunma: `app/OhmCore/**` (T-026b paralelde Governor/Journal'ı değiştiriyor; OhmCore'da eksik bir public API gerekirse DUR ve `.result.md`'ye yaz), `OhmRules` bağlantısı (T-035), Views (yalnız veri kaynağı değişir).

## Davranış (ADR 0001 §2-3, ADR 0002, ADR 0004)
1. Tick sırası: `ticks` akışını tek tüketici okur; her tick'te önce `await ledger.record`, sonra `forecaster.observe`, `runawayDetector.observe(tick:visibility:)`, sonra UI anlık görüntüsü (`@MainActor`'a tek atlama). T-029 tamponu sayesinde üretici beklemez.
2. Ledger dosyası App Group kapsayıcısında (`group.dev.ohm`, ADR 0002'deki yol). `todayReceipt` ledger okuyucusundan, UI'ı bloklamadan ve seyrek (ör. 30 sn veya popover açılınca).
3. Governor: açılışta `JournalSession` + `startProtection()`; `tick()` düzenli; `WorkspaceEvent`'ler NSWorkspace bildirimlerinden; uygulama kapanırken `shutdown()` (NSApplication willTerminate). UI eylemleri (`toggleECore`, `toggleFreeze`, runaway eylemleri) `perform(GovernorCommand)` ile, origin `.manual` / `.runaway`. Arka plan süreci dondurma ek onayı ADR 0004 §2: UI onay vermeden `confirmedBackground: true` gönderme; mevcut Views'da onay yoksa dondurmayı reddet ve veto nedenini göster (UI eklemek T-035/T-036 işi).
4. `RunawayNotifier` (T-032) bağlanır: `.started` → bildirim; yanıt → aynı `perform` yolu; `quit` önce kimliği yeniden doğrular, sonra `NSRunningApplication.terminate()` (paketsizde SIGTERM).
5. Enerji bütçesi: runtime kendisi boşta hedefleri bozmamalı (PLAN: bellek < 40 MB, CPU < %0,5). Timer yok; zaman tick'ten gelir. Governor tick'i örnekleme ritmine bağlı.
6. `--runtime-smoke <saniye>` argümanı: UI açmadan runtime'ı çalıştırır, sonunda stdout'a tek satır JSON basar: `{"ticks":N,"ledgerMinuteRows":N,"watts":X,"runaways":N,"protection":"..."}` ve çıkar (kapıyı şef bununla koşar).

## Rev 1 — şef kapısı FAIL (2026-09-30, sandbox dışında, imzalı Debug build)
Geçenler: `xcodebuild` SUCCEEDED; `Ohm --runtime-smoke 90` → `{"ledgerMinuteRows":3,"watts":6.9,"ticks":84,"runaways":0,"protection":"spawnedWatcher"}`, geride süreç yok; ikiliyi doğrudan GUI modunda başlatınca ohm-thawd çalışıyor, kill -9 sonrası izleyici çıkıyor.
**Kırmızı (tekrarlanabilir, 2/2):** Uygulama `open -n Ohm.app` ile (LaunchServices, kullanıcının gerçek başlatma yolu) açılınca runtime **hiç başlamıyor**: 38 sn sonra süreçte ledger/lock dosyası açık değil, `ledger.sqlite-wal` yazılmıyor, `ohm-thawd` yok. Başlangıç `OhmApp.swift:111` `applicationDidFinishLaunching { source?.start() }` üzerinden; hipotez: `open` yolunda delegate'in `source`'u didFinishLaunching'den sonra atanıyor (yarış). Doğrula, varsayma.
Düzeltme: başlangıç, başlatma yolundan ve sıralamadan bağımsız ve tam bir kez olmalı (idempotent). Kanıt olarak: `open` yoluyla da çalıştığını gösteren bir yol ekle — ör. `--runtime-smoke` dışındaki normal başlatmada runtime başlayınca stderr'e (veya `os_log` subsystem `dev.ohm`, category `runtime`) tek satır `runtime started protection=<mode>` yaz; şef `log show --predicate 'subsystem == "dev.ohm"'` ile kontrol edecek.
Ayrıca ölç ve raporla (düzeltme gerekmez, T-061b ölçecek): doğrudan başlatmada 15. sn RSS 91 MB görüldü (hedef boşta < 40 MB; ilk 15 sn boşta sayılmaz).
